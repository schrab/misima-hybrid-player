# Number-Key Cue Points & Transport Hotkeys — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Bare number keys cue playback to 10 %…90 % of the loaded track (`0` = start) and start playing from there; `Space`, `←`/`→`, `z`/`x` provide classic transport.

**Architecture:** Two pure helper functions in `player.rs` hold all the new arithmetic and are unit-tested without touching global state. `cue_fraction` composes them with the existing `seek_secs` path (so `seek_gen` still flushes the stretcher tail) and promotes a paused player to playing. Two thin Tauri commands expose it; a second DOM `keydown` listener in `main.ts` maps bare keys to those commands. No DSP code changes.

**Tech Stack:** Rust (Tauri 2 commands, parking_lot locks), TypeScript (Canvas 2D frontend), `cargo test` / `cargo check` / `npm run build`.

**Spec:** `docs/superpowers/specs/2026-10-03-cue-keys-design.md` (commit `31406c6`).

## Global Constraints

- Cue fractions are fixed at 10 % steps: key `N` → `N * 0.10`. Key `0` → `0.0`.
- The fraction is clamped to `0.0..=0.9` inside `cue_target_secs`, so a bad argument can never aim past 90 %.
- The cue target backs off 50 ms from the end of the track; seeking to the exact last sample leaves the renderer nothing to pull and looks like a stuck player.
- The hotkey listener must ignore any press with Ctrl, Cmd or Alt held, so `Ctrl+0` (zoom reset) and `Ctrl+D` (zoom toggle) keep working and modified presses are never swallowed.
- Hotkeys are window-focus only (DOM `keydown`). Do **not** register them as Rust global shortcuts.
- Hotkeys work with both the number row and the numpad — `ev.key` alone identifies the digit.
- No allocation and no mutex traffic added to the audio callback. `seek_secs` runs on the IPC thread, not the audio thread; it takes `samples.read()` only to compute a length, then drops the guard before touching `play_pos`/`cursor`.
- `cargo test` must stay at 39 passing tests plus 1 `#[ignore]`d smoke test; `cargo check` must emit zero warnings.
- Player tests share a process-global `SharedPlay`. If the new shared-state test ever interleaves badly with `decode_load_sets_shared_buffer`, run `cargo test audio::player -- --test-threads=1` (both tests pass under serial execution).

```rust
/// Clamp a seek time to a frame index inside the loaded buffer.
/// `None` when there is nothing to seek into (empty buffer or zero rate) —
/// the caller decides whether that is an error or a no-op.
fn clamped_frame(secs: f64, sr: f64, total_frames: usize) -> Option<usize> {
    if sr <= 0.0 || total_frames == 0 {
        return None;
    }
    // One frame of margin: the cursor is consumed as a read index, and the
    // renderer needs at least one frame left to emit anything.
    let last = total_frames.saturating_sub(1);
    let frame = (secs.max(0.0) * sr).round().max(0.0);
    // `as usize` saturates, so an absurd seek time clamps to `last` too.
    Some((frame as usize).min(last))
}

/// Cue target in seconds for `fraction` of a track lasting `dur` seconds.
/// `None` when there is no track to cue into.
fn cue_target_secs(fraction: f64, dur: f64) -> Option<f64> {
    if !dur.is_finite() || dur <= 0.0 {
        return None;
    }
    // Never aim at the very last sample: nothing would be left to render and
    // the player would look stuck at the end.
    let max = (dur - 0.05).max(0.0);
    Some((fraction.clamp(0.0, 0.9) * dur).min(max))
}

pub fn seek_secs(secs: f64) {
    let shared = shared();
    let sr = shared.sample_rate.load(Ordering::SeqCst) as f64;
    let ch = shared.channels.load(Ordering::SeqCst).max(1);
    // Drop the samples guard before taking play_pos — never hold two locks.
    let total_frames = { shared.samples.read().len() / ch };
    let frame = clamped_frame(secs, sr, total_frames).unwrap_or_else(|| {
        // Nothing loaded yet: still record the intent, clamped at zero.
        (secs.max(0.0) * sr).round().max(0.0) as usize
    });
    *shared.play_pos.lock() = frame as f64;
    shared.cursor.store(frame * ch, Ordering::SeqCst);
    shared.ended.store(false, Ordering::SeqCst);
    shared.seek_gen.fetch_add(1, Ordering::SeqCst);
}
```

```rust
/// Length of the loaded track in seconds, from the decoded buffer.
/// 0.0 when nothing is loaded. Read from the real buffer rather than the
/// playlist's `mm:ss` string, which is a display hint and minutes-only.
pub fn duration_secs() -> f64 {
    let shared = shared();
    let sr = shared.sample_rate.load(Ordering::SeqCst) as f64;
    if sr <= 0.0 {
        return 0.0;
    }
    let ch = shared.channels.load(Ordering::SeqCst).max(1);
    let frames = { shared.samples.read().len() / ch };
    frames as f64 / sr
}

/// Cue to `fraction` (clamped to 0.0..=0.9) of the loaded track, starting
/// playback if the player was paused. Returns the target position in
/// seconds, or -1.0 when nothing is loaded.
pub fn cue_fraction(fraction: f64) -> f64 {
    let target = match cue_target_secs(fraction, duration_secs()) {
        Some(t) => t,
        None => return -1.0,
    };
    let shared = shared();
    let was_playing = shared.playing.load(Ordering::SeqCst);
    // seek_secs bumps seek_gen, which flushes the WSOLA/vocoder tail — a cue
    // must not drag the previous position's sound along with it.
    seek_secs(target);
    if !was_playing {
        play();
    }
    target
}

/// Flip between playing and paused, returning the new playing state.
pub fn toggle_play() -> bool {
    if shared().playing.load(Ordering::SeqCst) {
        pause();
        false
    } else {
        play();
        true
    }
}
```

```ts
/** m:ss for the status line. */
function fmtTime(secs: number): string {
  const s = Math.max(0, Math.floor(secs));
  return `${Math.floor(s / 60)}:${String(s % 60).padStart(2, "0")}`;
}

// Bare-key transport and cue hotkeys. Modified presses are left alone so the
// Ctrl/Cmd zoom combos above keep working, and so we never swallow a key the
// user meant for something else. Window focus only — not a global shortcut.
window.addEventListener("keydown", (ev) => {
  if (ev.ctrlKey || ev.metaKey || ev.altKey) return;

  // 0..9 → 0%..90% of the loaded track. ev.key matches numpad digits too.
  if (/^[0-9]$/.test(ev.key)) {
    ev.preventDefault();
    const pct = Number(ev.key) * 10;
    void invoke<number>("cue_percent", { fraction: pct / 100 })
      .then((target) => {
        status = target < 0 ? "No track" : `CUE ${pct}% ${fmtTime(target)}`;
      })
      .catch((err) => console.warn("cue_percent failed", err));
    return;
  }

  switch (ev.key) {
    case " ":
      ev.preventDefault();
      void invoke<boolean>("toggle_play")
        .then((playing) => {
          status = playing ? "Playing" : "Paused";
        })
        .catch((err) => console.warn("toggle_play failed", err));
      return;
    case "ArrowLeft":
    case "ArrowRight": {
      ev.preventDefault();
      const delta = ev.key === "ArrowRight" ? 10 : -10;
      void invoke<number>("get_position")
        .then((pos) => {
          const target = Math.max(0, pos + delta);
          return invoke<void>("seek", { seconds: target }).then(() => target);
        })
        .then((target) => {
          status = `SEEK ${delta > 0 ? "+" : "-"}${Math.abs(delta)} ${fmtTime(target)}`;
        })
        .catch((err) => console.warn("seek failed", err));
      return;
    }
    case "z":
    case "Z":
      ev.preventDefault();
      void invoke("prev")
        .then(() => {
          status = "Prev";
        })
        .catch((err) => console.warn("prev failed", err));
      return;
    case "x":
    case "X":
      ev.preventDefault();
      void invoke("next")
        .then(() => {
          status = "Next";
        })
        .catch((err) => console.warn("next failed", err));
      return;
    default:
      return;
  }
});
```

The `status` assignments sit on the promise callbacks, which run after the current frame's draw, so the text appears on the next `requestAnimationFrame` — same as every other status write in this file.
